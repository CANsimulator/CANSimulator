# Learn the CAN Bus Protocol

A **high-fidelity, interactive reference** for Controller Area Network (CAN) — ISO 11898. Each topic pairs concise, spec-grounded explanations with live widgets and visualizations so you can see how a CAN bus actually behaves.

## Start here

- **[Introduction to CAN](/docs/introduction)** — What CAN is, why it exists, and where it runs
- **[Physical Layer](/docs/physical-layer)** — CANH / CANL, termination, bus topology, voltage levels
- **[Frame Format](/docs/frame-format)** — Every bit of the standard and extended data frame, annotated

Additional topics come online as the reference expands: **arbitration**, **bit timing**, **error handling**, and **higher-layer protocols** (UDS, J1939, CANopen).

> **New to CAN?** Read in order: [Introduction](/docs/introduction) → [Physical Layer](/docs/physical-layer) → [Frame Format](/docs/frame-format).

## Who this is for

- **Embedded systems engineers** building or debugging CAN nodes
- **Automotive diagnostics trainees** learning UDS, J1939, or OBD-II
- **Students and self-learners** who want to visualize protocol behavior without expensive lab hardware

## What makes this different

This documentation ships with an **interactive CAN simulator** you can open in a new tab. Every concept has a corresponding live demonstration — arbitration between nodes, bit-timing sample points, differential voltage traces — without installing drivers or wiring a transceiver.
