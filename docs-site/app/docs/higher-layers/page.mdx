# Higher-Layer Protocols

> **Coming soon.** This page is scaffolded for Phase 2. It will introduce the main application-layer protocols that run on top of raw CAN frames and show where CAN stops and each protocol begins.

Topics planned:

- **ISO-TP (ISO 15765-2)** — segmentation, flow control, multi-frame messages
- **UDS (ISO 14229)** — diagnostic services, sessions, negative response codes
- **SAE J1939** — heavy-duty vehicle networking, PGNs, address claiming
- **CANopen** — industrial automation object dictionary and PDOs
- **OBD-II** — emissions diagnostics on passenger vehicles
